
Виртуальные терминальные линии (VTY — Virtual Teletype Lines) — это логические линии на коммутаторе или маршрутизаторе Cisco, через которые администратор может удалённо подключаться к устройству по сети, например через SSH или Telnet.

**Например, администратор сидит в другом кабинете и хочет настроить коммутатор. Он запускает SSH-клиент и подключается к `192.168.0.1`. Устройство принимает соединение через настроенную VTY-линию и предоставляет командную строку после успешной аутентификации.**

Переход к настройке виртуальной консольной линии.
```
line vty 0 4
```
Переход к настройке VTY-линий с 0 по 4. Они используются для удалённых подключений к коммутатору по сети.

Шаг 2. Просмотр доступных протоколов

```
Switch(config-line)# transport ?
```

Коммутатор предлагает два параметра:
- `input` — протоколы для входящих подключений к коммутатору.
- `output` — протоколы для исходящих подключений, инициируемых самим устройством.

Шаг 3. Выбор протокола для входящих соединений

```
Switch(config-line)# transport input ?
```

Доступны следующие варианты:

| Команда  | Значение                                                 |
| -------- | -------------------------------------------------------- |
| `all`    | Разрешить все поддерживаемые протоколы                   |
| `none`   | Запретить все протоколы удалённого терминального доступа |
| `ssh`    | Разрешить SSH                                            |
| `telnet` | Разрешить Telnet                                         |
```
transport input telnet
```

Шаг 4. Включение проверки учётных данных

```
Switch(config-line)# login local
```

Коммутатор будет проверять логин и пароль по локальной базе пользователей, например по учётной записи `admin`, которую ты создавал ранее.

```
end
wr mem
```

- `end` — выход из режима конфигурации в `Switch#`.
- `wr mem` — сокращение от `write memory`; сохраняет текущую конфигурацию в постоянную память.
