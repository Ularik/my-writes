```
enable
configure terminal
username admin privilege 15 paassword cisco
line console 0 
login local
```

## 1. Что делает каждая команда

| Команда                                      | Объяснение                                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------- |
| `enable`                                     | Переход в привилегированный режим `Switch#`.                                    |
| `configure terminal`                         | Переход в режим глобальной конфигурации `Switch(config)#`.                      |
| `username admin privilege 15 password cisco` | Создание пользователя `admin` с уровнем привилегий 15 и паролем `cisco`.        |
| `line console 0`                             | Переход к настройке физической консольной линии.                                |
| `login local`                                | Включение проверки логина и пароля по локальной базе пользователей коммутатора. |

Обрати внимание: в твоей команде написано `paassword` — это опечатка. Правильное слово — `password`. Если коммутатор не распознаёт команду, введи её правильно.

## 2. Как команды работают вместе

Создаём пользователя

`username admin ...`

Настраиваем консоль

`line console 0`

Включаем локальную аутентификацию

`login local`

При следующем входе

Логин: `admin`

Пароль: `cisco`

## 3. Что означает `privilege 15`?

В Cisco IOS уровни привилегий обычно находятся в диапазоне от 0 до 15.

- 0 — минимальный набор команд.
    
- 1 — обычный пользовательский режим `Switch>`.
    
- 15 — полный привилегированный доступ, обычно соответствующий `Switch#`.
    

Пользователь с уровнем 15 может выполнять административные команды, в том числе изменять конфигурацию устройства.

## 4. Полная правильная последовательность

Для учебного стенда можно использовать такой вариант:

```
Switch> enable
Switch# configure terminal
Switch(config)# username admin privilege 15 secret cisco
Switch(config)# line console 0
Switch(config-line)# login local
Switch(config-line)# end
Switch#
```

Здесь я использовал `secret` вместо `password`: это предпочтительный вариант, поскольку IOS хранит пароль в защищённом виде, а не в открытом тексте.

Чтобы проверить конфигурацию:

```
Switch# show running-config
```

Для проверки настроек локального пользователя можно также посмотреть соответствующую строку конфигурации.
