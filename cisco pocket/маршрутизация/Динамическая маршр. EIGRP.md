Также как OSPF только без loopbox, и без area 

```
router eigrp 1
	network 192.168.20.0 255.255.255.0
	network 10.10.10.0 255.255.255.252 
	no auto-summary
	exit
```

### Выход в интернет или маршрут по дефолту
```
ip route 0.0.0.0 0.0.0.0 212.212.54.2
router eigrp 1
	redistribute static
```


### Проверить таблицу маршрутизации
```
show ip eigrp neighbors
```
