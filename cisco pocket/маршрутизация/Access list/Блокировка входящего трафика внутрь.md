Правило работает сверху вних
Блокировка ставится на access-list, который вешается на порт роутера

На нашем маршрутизаторе у которого белый ip на внешнем порту
```
ip access-list extended FROM-OUTSIDE
	permit ip any host 212.212.60.80
```

где 
ip - ip пакеты
any - любой источник
host 212.212.60.80 - конечный адрес ip маршрутизатора

**В итоге мы разрешили любые обращения только на конкретный ip маршрутизатора, если злоумышленник попытается зайти дальше к нам на локальные компьютеры, то у него это не выйдет. 
К примеру, он взломал маршрутизатор провайдера и может на нем прописать роуты 
ip route 192.168.0.0 255.255.255.0 212.212.60.80 - дает выход к внутренним локальным ip адресам и дальше пинговать подбором комбинации ip 192.168.2.1, 192.168.3.2...
**

После этот acces лист нужно назначить на порт маршрутизатора
```
int gig0/0/0
	ip access-group FROM-OUTSIDE in
```

in - входящий трафик 

### Защита роутера от telnet взлома
```
ip access-list extended FROM-OUTSIDE
	deny tcp any host 212.212.60.80 eq telnet
	
int gig0/0/1
	ip access-group FROM-OUTSIDE
```

deny - запретить
tcp - протокол tcp использует telnet
any - любой
eq telnet - порт telnet


Можно также вешать access листы на порты между внутренними сетями.
