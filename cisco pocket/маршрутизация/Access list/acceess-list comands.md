```
permit tcp 192.168.20.0 0.0.0.255 host 212.212.54.20 eq www
permit ip host 192.168.20.2 host 212.212.54.20
deny ip 192.168.20.0 0.0.0.255 host 212.212.54.20
permit ip any any
```

#### 1. Разрешить TCP-трафик из подсети 192.168.20.0/24
```
permit tcp 192.168.20.0 0.0.0.255 host 212.212.54.20
```
Что означает:
- `permit` — разрешить.
- `tcp` — разрешить только TCP-протокол.
- `192.168.20.0` — исходная сеть.
- `0.0.0.255` — wildcard mask, охватывает адреса от `192.168.20.0` до `192.168.20.255`.
- `host 212.212.54.20` — конкретный IP-адрес назначения.

Результат: всем устройствам из подсети `192.168.20.0/24` разрешено устанавливать TCP-соединения с сервером `212.212.54.20`.

#### 2. Разрешить весь IP-трафик конкретному компьютеру

```
permit ip host 192.168.20.2 host 212.212.54.20
```

- `permit` — разрешить.
- `ip` — разрешить любой IP-протокол (TCP, UDP, ICMP и другие).
- `host 192.168.20.2` — конкретный компьютер-источник.
- `host 212.212.54.20` — конкретный сервер назначения.

Результат: компьютеру `192.168.20.2` разрешён любой IP-трафик к серверу `212.212.54.20`.
Например:
- TCP — HTTPS, SSH.
- UDP — DNS.
- ICMP — Ping.

#### 3. Запретить трафик от конкретного IP

```
deny ip 192.168.20.0 0.0.0.255 host 212.212.54.20
```
- `deny` — запретить.
- `ip` — запретить любой IP-трафик.
- `192.168.20.0 0.0.0.255` — из этой подсети.
- `host 212.212.54.20` — конкретный сервер назначения.

Результат: запрещается любой IP-трафик от `192.168.20.0` к `212.212.54.20`.

#### 4. Разрешить весь остальной трафик

```
permit ip any any
```

- `permit` — разрешить.
- `ip` — любой IP-протокол.
- `any` — любой адрес источника.
- `any` — любой адрес назначения.
Результат: весь остальной IP-трафик разрешён.
