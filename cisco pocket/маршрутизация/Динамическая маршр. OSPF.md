
#### Посмотреть таблицу маршрутизации
```
show ip route
```


Чтобы связать другой маршрутизатор нужно задать ip портам и соединить их
```
int gig0/0/0
	encapsulation dotl
	ip address 10.10.10.1 255.255.255.252
	exit
```

Далее создаем протокол ospf
```
int loopback 0
	ip address 192.168.100.1 255.255.255.0
	exit
router ospf 1
	network 192.168.20.0 255.255.255.0 area 0
	network 192.168.30.0 255.255.255.0 area 0
	network 10.10.10.0 255.255.255.252 area 0
	exit
```

На втором и третьем пишем то же самое, но меняем принадлежащие сети 0.30, 0.20...
```
int loopback 0
	ip address 192.168.100.2 255.255.255.0
	exit
router ospf 1
	network 10.10.20.0 255.255.255.252 area 0
	network 10.10.10.0 255.255.255.252 area 0
	exit
```

```
int loopback 0
	ip address 192.168.100.3 255.255.255.0
	exit
router ospf 1
	network 192.168.2.0 255.255.255.0 area 0
	network 10.10.20.0 255.255.255.252 area 0
	exit
```

## Чтобы вывести роутер10 в интернет
Нужно на нём выполнить команды для nat 
```
int gig0/2
	ip nat outside
	exit
int gig0/1
	ip nat inside
	exit
int gig0/0
	ip ant inside
	exit
	
ip route 0.0.0.0 0.0.0.0 212.212.64.1
ip nat inside source list FOR-NAT interface gig0/2 overload
router ospf 1
	default-information originate
```

Команда:
```
router ospf 1
	default-information originate
```
делает устанавливает для других маршрутизаторов выход по умолчанию тоже адресс - 212.212.64.1
