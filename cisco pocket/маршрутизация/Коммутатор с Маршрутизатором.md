
### Коммутатор Л2 с маршрутизатором между внутренними сетями vlan
**маршрутизация между внутренними сетями vlan**.  создаем sub интерфейсы для одного fastEthernet, который подключен к коммутатору, сначала поднимаем его

```
int fastEthernet 0/0
	no shutdown
	
int fastEthernet 0/0.2  - 2 это номер суб интерфейса
encapsulation dot1Q ?
encapsulation dot1Q 2
ip add
ip address 192.168.2.1 255.255.255.0
no shutdown
exit

...
```

Далее на коммутаторе 2 уровня устанавливаем trunk мод для соединения с маршрутизатором
```
switchport mode trunk
switchport trunk allowed vlan 2,3
```

### Коммутатор Л2 с маршрутизатором
**Без маршрутизации (С одним только vlan 4 на коммутаторе)**
На Маршрутизаторе ставим ip из подсети .4.0 
Например:
```
int gig0/0/0
	ip address 192.168.4.10 255.255.255.0
```

Главное, чтобы:
- IP маршрутизатора принадлежал той же подсети, что и устройства VLAN 4.
- На ПК в качестве шлюза был указан именно IP маршрутизатора.

Далее на коммутаторе делаем switchport mode access как и к любому другому порту для порта с роутером
```
switchport mode access
switchport access vlan 4
```

Далее пингуем на роутере
```
ping 192.168.4.1
ping 192.168.4.2
```

Если же в дальнейшем планируется добавить ещё vlan (5), то на роутере нужно настроить сабинтерфейсы
```
int gig0/0/0
	no ip address 
	exit
int gig0/0/0.4
	encapsulation dot1Q 4 - важно, цифра должна совпадать
	ip address 192.168.4.10 255.255.255.0
	no shutdown

```
На коммутаторе ставим trunk mode
```
switchport mode trunk
switchport trunk allowed vlan 4
```

### Маршрутизатор с Л3 коммутатором
На коммутаторе 3 уровня уже работает своя маршрутизация, поэтому нужно создать доп vlan (5), на нём определить ip 192.168.5.2 255.255.255.0
```
vlan 5
	name VLAN5
	exit
int vlan 5
	ip address 192.168.5.2 255.255.255.0
	exit
```
