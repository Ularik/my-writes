Простая настройка без серверов производится на маршрутизаторе напрямую. В случае использования dhcp-сервера, производится на сервере, а маршрутизатор лишь перенаправляет трафик к нему.

На маршрутизаторе

### 1. Настройка интерфейса маршрутизатора

```
interface gig0/0/0
 no shutdown
 ip address 192.168.1.1 255.255.255.0
 exit
```
- `no shutdown` — включить интерфейс.
- `ip address` — назначить IP-адрес интерфейсу
- `192.168.1.1` — адрес маршрутизатора, который будет шлюзом для устройств.
- `255.255.255.0` — маска подсети.
### 2. Создание DHCP-пула

```
ip dhcp pool DHCP
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8
 exit
```

- `ip dhcp pool DHCP` — создать пул DHCP с названием DHCP.
- `network` — указать сеть, из которой будут выдаваться адреса.
- `default-router` — передать клиентам адрес шлюза.
- `dns-server` — передать клиентам DNS-сервер Google.

### 3. Исключение IP-адресов

```
ip dhcp excluded-address 192.168.1.100
ip dhcp excluded-address 192.168.1.1
```

Эти команды запрещают DHCP-серверу выдавать указанные IP-адреса.

Например:
- `192.168.1.1` — зарезервирован под шлюз маршрутизатора.
- `192.168.1.100` — зарезервирован под другое устройство, например сервер или принтер.

### 5. Проверка DHCP

После настройки используй команды:

```
show ip dhcp pool
show ip dhcp binding
show ip dhcp conflict
show ip interface brief
```
