
### На маршрутизаторе используем два порта: одни для внутренней сети, второй - выход в инет

На внутреннем порту ставим настройки:

Если сеть маршрутизируется на роутере через сабинтерфейсы
```
int gig0/0/0.2
	ip nat inside
	exit
int gig0/0/0.3
	ip nat inside
	exit
```
Если просто через целый порт:
```
int gig0/0/0
	ip nat inside
```

### Далее создаем access-list, куда записывается какой vlan имеет доступ в инет

```
ip access-list standard FOR-NAT
	permit 192.168.2.0 0.0.0.255
	permit 192.168.3.0 0.0.0.255

```

### Теперь настраиваем интерфейс, который подключён к провайдеру

Теперь настраиваем интерфейс, который подключён к провайдеру:

```
interface GigabitEthernet0/0/1
 ip address dhcp
 ip nat outside
 no shutdown
```
предварительно на нем ставим белый ip
```
int gig0/0/1
	ip address 213.68.10.2 255.255.255.252
	exit
```

Настраиваем маршрутизацию на все неизвестные сети наружу через внешний порт 213.68.10.1
```
ip route 0.0.0.0 0.0.0.0 213.68.10.1
ip nat inside source list FOR-NAT interface gig0/0/1 overload
```
gig0/0/1 - внешний порт наружу
### Если нужно сервер вытащить в интернет 

На роутере с белым ip
```
ip nat inside source static tcp 192.168.3.2 80 213.234.10.2 80
```

192.168.3.2 - ip сервера
213.68.10.2 - белый ip
