### Маршрутизация между локальными сетями
1. На коммутаторе настраиваем для портов vlan-ы [[Создание vlan 2 и разделение на vlan]]
2. Создаем и задаем ip для vlan, шлюзы определяем на L3 коммутаторе
	```
	vlan 2
		name buh
		exit
	vlan 3
		name user
		exit
	int vlan 2
		ip address 192.168.2.1 255.255.255.0
		exit
	int vlan 3
		ip address 192.168.2.1 255.255.255.0
		exit
	```
	
3. вводим команды для определения fa0
```
int fa0/1
	switchport trunk encapsulation dot1q
	switchport mode trunk
	switchport trunk allowed vlan 2,3
ip routing
```
