В Cisco IOS есть несколько режимов командной строки (CLI). Каждый режим предназначен для определённых задач: просмотра состояния устройства, настройки всей системы или изменения конкретного интерфейса.

Главное — научиться узнавать режим по приглашению командной строки (`Switch...#`).

## 1. Основные режимы Cisco

1. User EXEC — пользовательский режим

`Switch>`

Начальный режим после подключения. Доступны базовые команды проверки, например `ping` и некоторые диагностические команды.

2. Privileged EXEC — привилегированный режим

`Switch#`

Вход через `enable`. Позволяет выполнять расширенную диагностику, смотреть конфигурацию и переходить к настройке.

Примеры: `show running-config`, `show ip interface brief`, `copy running-config startup-config`.

3. Global Configuration — глобальная конфигурация

`Switch(config)#`

Вход через `configure terminal`. Здесь настраивают параметры всего устройства: пользователей, имя коммутатора, маршрутизацию и другие общие настройки.

4. Interface Configuration — настройка интерфейса

`Switch(config-if)#`

Вход, например, через `interface vlan 1` или `interface gigabitEthernet 0/1`. Здесь настраивают конкретный интерфейс.

5. Line Configuration — настройка входа через консоль или виртуальную линию

`Switch(config-line)#`

Вход через `line console 0` или `line vty 0 4`. Здесь задают параметры консольного и удалённого терминального доступа.
