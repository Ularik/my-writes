Есть два вида агрегирования
### Динамическое агрегирование 
	LACP (Link Aggregation Control Protocol) 
	PAgP (Port Aggregation Protocol) 

### Статическое агрегирование

--------------------------------------------

Порты должны иметь одинаковые: 
● скоростью (speed), 
● режимом дуплекса (duplex mode), 
● native VLAN, 
● диапазон разрешенных VLAN, 
● trunking status, 
● типом интерфейса. 
Подробнее о EtherChannel здесь

### Настройка Статического агрегированя

Выбираем два порта для агрегирования и соединения между собой. Тут у нас будут fastEthernet 0/1 и 0/2/, объединяем их в группу channel-group 1

**На Switch0:** 
	int range fa0/1-2 
	channel-group 1 mode on  - объединяем их в port-channel 1

**На Switch1:**
	int range fa0/1-2 
	channel-group 1 mode on

### Настройка динамического агрегирования

Берем коммутатор 3 уровня. Также выбираем два порта для агрегирования и соединения между собой. Тут у нас будут fastEthernet 0/1 и 0/2
```
conf t
	int range fa0/1-2
		channel-protocol lacp
		channel-group 1 mode active
```
Повторяем то же самое для следующей группы каналов для агрегирования по lacp
```
conf t
	int range fa0/3-4
		channel-protocol lacp
		channel-group 2 mode active
		exit
	int range fa0/5-6
		channel-protocol lacp
		channel-group 3 mode active
```

#### Далее заходим в настройки коммутаторов 2 уровня
Везде указываем нужные порты это у всех 1-2, но разные группы
```
conf t
	int range fa0/1-2
		channel-protocol lacp
		channel-group 1 mode active
conf t
	int range fa0/1-2
		channel-protocol lacp
		channel-group 2 mode active
conf t
	int range fa0/1-2
		channel-protocol lacp
		channel-group 3 mode active
```


### Как теперь быть, если есть несколько vlan?
Переключить mode trunk уже не на физическом порту как например на gigabitEthernet 1, а на логическом порту port-channel

```
interface port-channel 1
switchport mode trunk
switchport trunk allowed vlan 2,3
```

### Как теперь быть, если есть несколько vlan, если на динамическом агрегировании по lacp?
На коммутаторе 3 уровня берём и делаем

Создаем нужные вланы и позволяем им проходить через trunk
```
vlan 2
	exit
vlan 3
	exit
	
interface port-channel 1
	switchport trunk encapsulation dot1q
	switchport mode trunk
	switchport trunk allowed 2,3
	exit
interface port-channel 2
	switchport trunk encapsulation dot1q
	switchport mode trunk
	switchport trunk allowed 2,3
	exit
```

На коммутаторах 2 уровня также настраиваем trunk для port-channel
```
interface port-channel 1
	switchport mode trunk
	switchport trunk allowed 2,3
```

```
interface port-channel 2
	switchport mode trunk
	switchport trunk allowed 2,3
```
