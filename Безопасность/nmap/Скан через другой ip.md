```
sudo nmap 10.129.2.28 -n -Pn -p 445 -O -S 10.129.2.200 -e tun0
```

| **Параметры сканирования** | **Описание**                                             |
| -------------------------- | -------------------------------------------------------- |
| `10.129.2.28`              | Сканирует указанную цель.                                |
| `-n`                       | Отключает разрешение DNS.                                |
| `-Pn`                      | Отключает запросы ICMP Echo.                             |
| `-p 445`                   | Сканирует только указанные порты.                        |
| `-O`                       | Выполняет сканирование обнаружения операционной системы. |
| `-S`                       | Сканирует цель, используя другой исходный IP-адрес.      |
| `10.129.2.200`             | Указывает исходный IP-адрес.                             |
| `-e tun0`                  | Отправляет все запросы через указанный интерфейс.        |
