```
nmap -sn 192.168.0.100/24 - всю подсеть на доступные адресса
nmap -O 192.168.0.100 - на версию операционной системы
nmap -Pn 192.168.0.100 - не отправлять ASMP пинг для проверки доступности, а сразу сканировать все порты
nmap -F 192.168.0.100 - быстрое сканирование на самые популярные порты
nmap -sV 192.168.0.100 - версии программ на портах
sudo nmap -A 192.168.0.100 - агрессивное сканирование
```

```
sudo nmap -oN scan.txt 192.168.0.100 - записать всю инфу из скана в файл
```
#### Режимы сканирвоания
```
-T0, T1 - медленное сканирование, для скрытности
-T2 - вежливый режим
-T3 - по умолчанию
-T4 - агрессивынй, быстрый режим
-T5 - супер быстрый, точность снижается
```
