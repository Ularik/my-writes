```
sudo nmap 10.129.2.28 -p50000 -sS -Pn -n --disable-arp-ping --packet-trace --source-port 53
```

| **Параметры сканирования** | **Описание**                                          |
| -------------------------- | ----------------------------------------------------- |
| `10.129.2.28`              | Сканирует указанную цель.                             |
| `-p 50000`                 | Сканирует только указанные порты.                     |
| `-sS`                      | Выполняет сканирование SYN на указанных портах.       |
| `-Pn`                      | Отключает запросы ICMP Echo.                          |
| `-n`                       | Отключает разрешение DNS.                             |
| `--disable-arp-ping`       | Отключает ARP-пинг.                                   |
| `--packet-trace`           | Показывает все отправленные и полученные пакеты.      |
| `--source-port 53`         | Выполняет сканирование из указанного исходного порта. |
